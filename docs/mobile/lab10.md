# №10. Мобильный клиент склада

Для запуска нужны заполненная база API и настроенные роли. Выполните [команды запуска](../../README.md#запуск-лабораторных-811), затем войдите как `admin`. Пользователь `reader` может просматривать каталог и обзор. Клиент запрашивает имя пользователя у сервера через `GET /auth/me`.

## Создание и исправление карточки

1. Откройте «Товары» и нажмите «Добавить товар». Введите «Клавиатура учебная», цену 15 000 (в поле введите `15000`), количество `8`. Выберите категорию «Электроника» и поставщика «Tech Supply».
2. Сохраните запись. Найдите её по слову «клавиатура». Проверьте название, остаток и цену в каталоге. Измените сортировку на «По остатку».
3. В меню карточки выберите «Изменить» и укажите цену `14000`. Снова откройте форму и убедитесь, что категория, поставщик и количество сохранились.
4. На экране «Обзор» проверьте итог. Добавление карточки увеличило суммарный остаток на 8 единиц, а её стоимость после изменения составляет 112 000 ₸.
5. Выйдите из профиля и войдите повторно. Найдите ту же запись. При удалении сначала нажмите «Отмена» и убедитесь, что карточка сохранилась, затем подтвердите удаление.

## От жеста до записи в БД

| Действие | Реализация |
| --- | --- |
| Переход между разделами | Нижняя панель; форму редактора открывает Navigator. После успешного сохранения редактор возвращает результат родительскому экрану. |
| Чтение | Клиент получает каталог через GET /items. Поиск и сортировка работают на загруженном списке. |
| Создание | Форма загружает категории и поставщиков через GET /catalog/references. POST /items передаёт выбранные ID и данные товара. |
| Изменение | PUT /items/{id} передаёт полную карточку. Ответ сервера определяет успех сохранения. |
| Удаление | После подтверждения DELETE /items/{id} удаляет карточку и связанные операции. Каталог обновляется. |
| Сеанс | Пароль скрыт при вводе. Учётные данные хранятся в памяти клиента до выхода. Для реального сервера используется HTTPS. |
| Сбой связи | Клиент показывает сообщение при сетевой ошибке или тайм-ауте. Серверная SQLite сохраняет ранее записанные товары. |

Название должно содержать от 1 до 200 символов после обрезки внешних пробелов. Цена должна быть конечным неотрицательным числом, количество — целым числом от нуля. Категория и поставщик обязательны. Ошибку конкретного поля можно исправить прямо в открытой форме. Ограничения и права также проверяет API.

Исходный код доступен по файлам [вход и навигация](../../mobile/lib/main.dart), [обзор, каталог и профиль](../../mobile/lib/inventory_views.dart), [редактор](../../mobile/lib/editor.dart), [HTTP-клиент](../../mobile/lib/warehouse_api.dart). Итоговые сценарии проверки собраны в [отчёте №11](lab11.md).
