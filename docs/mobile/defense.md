# Мобильный склад — защита на 6 минут

## 0:00–0:45 · Задача сотрудника

Показать обзор. Сотрудник проверяет остаток рядом со стеллажом, администратор исправляет карточку на месте. Назвать три показателя с экрана и объяснить один расчёт — стоимость запасов складывается из цены каждого товара, умноженной на его количество.

## 0:45–1:30 · От телефона до базы

Открыть [схему из №9](lab9.md#три-слоя). Проследить путь сохранённой карточки от формы Flutter через JSON и FastAPI до SQLite. Показать роль в профиле. Справочники на телефоне и в Swagger берутся из одной базы.

## 1:30–2:30 · Найти нужную позицию

Перейти на вкладку «Товары», найти «Мышь», очистить поиск и включить сортировку по остатку. Пояснить, какую позицию стоит проверить первой. При отсутствии совпадений показать сообщение и вернуться к полному списку.

## 2:30–4:00 · Завести и исправить карточку

От имени admin добавить «Клавиатура учебная» с количеством 8. Сначала оставить название пустым, затем исправить ошибку. Выбрать категорию и поставщика, сохранить и показать присвоенный ID. Поменять цену с 15000 на 14000. Итоговая стоимость этой позиции составит 112000 ₸.

## 4:00–5:00 · Сохранность и права

Выйти и войти как reader. Найти карточку с тем же ID и обновлённой ценой. Показать доступные действия читателя. Вернуться как admin, отменить удаление, затем подтвердить и убедиться, что поиск больше не находит позицию.

## 5:00–6:00 · Доказательства

Открыть [план испытаний и результаты](lab11.md), затем показать успешные проверки конкретного коммита в GitHub Actions. Объяснить, как тест повторного чтения выявляет потерю данных, а проверка 403 защищает путь записи вне интерфейса. Завершить границами демонстрации: данные сохраняет сервер, для новых операций клиенту нужна связь.
